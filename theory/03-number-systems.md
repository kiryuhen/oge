# Системы счисления

> Нужна для задания: [10 — сравнение чисел в разных системах](../tasks/10-number-systems.md).

## Основные понятия

**Позиционная система счисления**: значение цифры зависит от её позиции (разряда).
**Основание** — сколько цифр используется; оно же — «вес» соседнего разряда.

| Система | Основание | Цифры |
|---|---|---|
| двоичная | 2 | 0, 1 |
| восьмеричная | 8 | 0 … 7 |
| десятичная | 10 | 0 … 9 |
| шестнадцатеричная | 16 | 0 … 9, A(10), B(11), C(12), D(13), E(14), F(15) |

Основание пишут маленьким индексом: $1011_2$, $75_8$, $\text{2F}_{16}$.

> [!NOTE]
> Цифра всегда **меньше** основания. Запись $129_8$ невозможна: в восьмеричной системе нет цифры 9.

## Перевод в десятичную систему (развёрнутая форма)

Нумеруем разряды **справа налево с нуля** и умножаем каждую цифру на основание в степени номера разряда:

$$1011_2 = 1\cdot2^3 + 0\cdot2^2 + 1\cdot2^1 + 1\cdot2^0 = 8 + 0 + 2 + 1 = 11$$

$$175_8 = 1\cdot8^2 + 7\cdot8^1 + 5\cdot8^0 = 64 + 56 + 5 = 125$$

$$\text{2F}_{16} = 2\cdot16 + 15 = 47$$

> [!TIP]
> **Двоичное → десятичное быстро.** Подпишите над разрядами степени двойки и сложите те, где стоит 1:
>
> ```
> 128 64 32 16  8  4  2  1
>   1  0  1  1  0  1  0  1   →  128 + 32 + 16 + 4 + 1 = 181
> ```

## Перевод из десятичной системы

**Деление с остатком**: делим на основание, пока частное не станет 0, затем записываем остатки **снизу вверх**.

```
 45 : 2 = 22  ост. 1   ▲
 22 : 2 = 11  ост. 0   │
 11 : 2 =  5  ост. 1   │  читаем снизу вверх
  5 : 2 =  2  ост. 1   │
  2 : 2 =  1  ост. 0   │
  1 : 2 =  0  ост. 1   │
```

$45 = 101101_2$.

**Быстрый способ для двоичной системы** — раскладываем на степени двойки:
$45 = 32 + 8 + 4 + 1$ → единицы в разрядах 32, 8, 4, 1:

```
32 16  8  4  2  1
 1  0  1  1  0  1   → 101101₂
```

## Двоичная ↔ восьмеричная ↔ шестнадцатеричная

Так как $8 = 2^3$ и $16 = 2^4$, одна восьмеричная цифра — это **3 двоичных разряда (триада)**, а одна шестнадцатеричная — **4 разряда (тетрада)**.

| 8-ричная | 2-ичная | | 16-ричная | 2-ичная | | 16-ричная | 2-ичная |
|---|---|---|---|---|---|---|---|
| 0 | 000 | | 0 | 0000 | | 8 | 1000 |
| 1 | 001 | | 1 | 0001 | | 9 | 1001 |
| 2 | 010 | | 2 | 0010 | | A | 1010 |
| 3 | 011 | | 3 | 0011 | | B | 1011 |
| 4 | 100 | | 4 | 0100 | | C | 1100 |
| 5 | 101 | | 5 | 0101 | | D | 1101 |
| 6 | 110 | | 6 | 0110 | | E | 1110 |
| 7 | 111 | | 7 | 0111 | | F | 1111 |

Пример: $10110110_2$ → группы по 4 **справа**: `1011 0110` → $\text{B6}_{16}$.
Группы по 3 справа: `10 110 110` → `010 110 110` → $266_8$.

## Сравнение чисел в разных системах (задание 10)

Самый надёжный путь: **перевести всё в десятичную** и сравнить. Пример:

> Найдите максимальное из чисел $\text{A3}_{16}$, $245_8$, $10100100_2$.

- $\text{A3}_{16} = 10\cdot16 + 3 = 163$
- $245_8 = 2\cdot64 + 4\cdot8 + 5 = 128 + 32 + 5 = 165$
- $10100100_2 = 128 + 32 + 4 = 164$

Ответ: **165**.

> [!TIP]
> **Прикидка.** Число с бо́льшим количеством разрядов в одной системе почти всегда больше. Двузначное 16-ричное число ≤ 255, трёхзначное 8-ричное ≤ 511, восьмиразрядное двоичное ≤ 255.

## Количество единиц в двоичной записи

> Сколько единиц в двоичной записи числа 200?

$200 = 128 + 64 + 8$ → три степени двойки → **3 единицы** ($11001000_2$).

Полезный трюк: $2^n - 1$ в двоичной записи — это $n$ единиц ($255 = 11111111_2$, $63 = 111111_2$).

## Проверка на Python (дома, не на экзамене)

```python
print(int("A3", 16), int("245", 8), int("10100100", 2))   # 163 165 164
print(bin(45), oct(45), hex(45))                         # 0b101101 0o55 0x2d
print(bin(200).count("1"))                              # 3
```

## Частые ошибки

> [!WARNING]
> - Нумерация разрядов начинается **с нуля и справа**.
> - Остатки при делении записывают **снизу вверх**, а не сверху вниз.
> - При разбиении на триады или тетрады группы отсчитывают **справа**, слева добавляют нули.
> - Ответ в задании 10 нужен **в десятичной системе**, без индекса.
