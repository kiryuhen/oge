# Глоссарий

Термины расположены по алфавиту. В скобках — номера заданий, где термин встречается.

| Термин | Определение |
|---|---|
| **Абсолютная ссылка** (14) | Ссылка на ячейку, которая не меняется при копировании формулы: `$A$1`. |
| **Алгоритм** (5, 6, 15, 16) | Понятная и точная последовательность действий, приводящая к результату. |
| **Алфавит** (1, 2) | Набор символов, из которых составляются сообщения. **Мощность алфавита** — число символов в нём. |
| **Байт** (1, 12) | Единица информации: 8 бит. |
| **Бит** (1) | Наименьшая единица информации: один двоичный разряд (0 или 1). |
| **Ветвление** (6, 15, 16) | Конструкция «если — то — иначе»: выбор действий в зависимости от условия. |
| **Вершина** (4, 9) | Точка графа (город, пункт). |
| **Высказывание** (3) | Утверждение, о котором можно сказать, истинно оно или ложно. |
| **Граф** (4, 9) | Набор вершин и соединяющих их рёбер. **Ориентированный** граф — рёбра со стрелками. **Взвешенный** — у рёбер есть веса (длины). |
| **Декодирование** (2) | Восстановление исходного сообщения по коду. |
| **Диапазон** (14) | Прямоугольный блок ячеек таблицы: `A2:D100`. |
| **Дизъюнкция** (3, 8) | Логическое ИЛИ: истинно, если истинно хотя бы одно из высказываний. В запросах — символ `\|`. |
| **Домен** (7) | Часть имени сервера. Читается справа налево: `ru` — домен верхнего уровня. |
| **Исполнитель** (5, 15) | Тот, кто выполняет алгоритм. **СКИ** — система команд исполнителя. |
| **Каталог (папка)** (11, 12) | Объект файловой системы, в котором хранятся файлы и другие каталоги. |
| **Кодировка** (1) | Таблица соответствия символов и их числовых кодов (КОИ-8, Windows-1251, Unicode). |
| **Конъюнкция** (3, 8) | Логическое И: истинно, только если истинны оба высказывания. В запросах — символ `&`. |
| **Круги Эйлера** (8) | Изображение множеств кругами для наглядного решения задач с И/ИЛИ. |
| **Маска файла** (12) | Шаблон имени: `*` — любое число любых символов, `?` — ровно один символ. |
| **Матрица смежности (весовая таблица)** (4) | Таблица, в которой на пересечении строки и столбца указан вес ребра между вершинами. |
| **Неравномерный код** (2) | Код, в котором коды символов имеют разную длину. |
| **Основание системы счисления** (10) | Количество цифр в системе; «вес» соседнего разряда. |
| **Относительная ссылка** (14) | Ссылка на ячейку, которая меняется при копировании формулы: `A1`. |
| **Отрицание (инверсия)** (3) | Логическое НЕ: меняет истинность на противоположную. |
| **Позиционная система счисления** (10) | Система, в которой значение цифры зависит от её позиции в записи числа. |
| **Префиксный код** (2) | Код, в котором ни один код не является началом другого (выполнено условие Фано). |
| **Протокол** (7) | Правила обмена данными в сети: `http`, `https`, `ftp`. |
| **Расширение файла** (12) | Часть имени файла после последней точки: `.txt`, `.jpg`. |
| **Ребро (дуга)** (4, 9) | Линия, соединяющая две вершины графа; дуга — ребро со стрелкой. |
| **Трассировка** (6) | Пошаговое выполнение программы с записью значений переменных. |
| **Условие Фано** (2) | Ни один код не является началом другого кода. Гарантирует однозначное декодирование. |
| **URL** (7) | Адрес ресурса в Интернете: `протокол://сервер/путь/файл`. |
| **Файл** (11, 12) | Именованная область данных на носителе. |
| **Формула** (14) | Выражение в ячейке, начинающееся со знака `=`. |
| **Цикл** (15, 16) | Повторение группы команд: «пока условие» (`while`, `нц пока`) или заданное число раз (`for`, `нц N раз`). |
| **Ячейка** (14) | Пересечение строки и столбца таблицы, имеет адрес (`B3`). |
