# Электронные таблицы (LibreOffice Calc и Excel)

> Нужна для задания: [14 — обработка данных в таблице](../tasks/14-spreadsheets.md).

С 2026 года на ОГЭ используют **LibreOffice Calc**: файл задания приходит в формате `.ods`, ответ тоже сохраняют в `.ods`. Excel работает почти так же, отличия показаны ниже.

## Основы

- **Ячейка** — пересечение столбца и строки: `B3`.
- **Диапазон** — прямоугольник ячеек: `A2:A1001`, `B2:D10`.
- **Формула** начинается со знака `=`: `=B2*C2`.
- Разделитель аргументов в русской версии — **точка с запятой**: `=СУММ(A1;B1)`.
- Десятичный разделитель — **запятая**: `3,14`.

## Относительные и абсолютные ссылки

| Ссылка | При копировании формулы вниз/вправо |
|---|---|
| `A1` | меняются и столбец, и строка |
| `$A$1` | не меняется ничего |
| `$A1` | столбец закреплён, строка меняется |
| `A$1` | строка закреплена, столбец меняется |

Клавиша **F4** (в Calc — **Shift+F4**) переключает виды ссылки.

**Автозаполнение:** напишите формулу в `E2`, выделите ячейку и **дважды щёлкните** по маленькому квадратику в правом нижнем углу. Формула скопируется вниз до конца данных.

## Главные функции для задания 14

| Функция (рус.) | Англ. | Что делает |
|---|---|---|
| `СУММ(диапазон)` | SUM | сумма |
| `СРЗНАЧ(диапазон)` | AVERAGE | среднее |
| `МАКС`, `МИН` | MAX, MIN | максимум, минимум |
| `СЧЁТ(диапазон)` | COUNT | количество чисел |
| `СЧЁТЕСЛИ(диапазон; условие)` | COUNTIF | количество ячеек, удовлетворяющих условию |
| `СЧЁТЕСЛИМН(диап1; усл1; диап2; усл2; …)` | COUNTIFS | количество строк, где выполнены **все** условия |
| `СУММЕСЛИ(диапазон; условие; диап_суммы)` | SUMIF | сумма по условию |
| `СРЗНАЧЕСЛИ(диапазон; условие; диап_среднего)` | AVERAGEIF | среднее по условию |
| `СРЗНАЧЕСЛИМН(диап_среднего; диап1; усл1; …)` | AVERAGEIFS | среднее по нескольким условиям |
| `ЕСЛИ(условие; если_да; если_нет)` | IF | выбор значения |
| `И(…)`, `ИЛИ(…)` | AND, OR | логические операции |
| `МЕСЯЦ(дата)` | MONTH | номер месяца из даты |

### Как писать условия

| Условие | Запись |
|---|---|
| равно тексту | `"Ю"` или ячейка с этим текстом |
| равно числу | `5` |
| больше 50 | `">50"` |
| не меньше 50 | `">=50"` |
| не равно «С» | `"<>С"` |
| больше значения в ячейке H1 | `">"&H1` |

> [!WARNING]
> У `СУММЕСЛИ` и `СРЗНАЧЕСЛИ` диапазон для суммирования стоит **последним**, а у `СРЗНАЧЕСЛИМН` и `СУММЕСЛИМН` — **первым**. Это частая путаница.

## Типовые приёмы

Таблица: A — округ, B — фамилия, C — предмет, D — балл (строки 2…1001).

**1. Сколько учеников округа «В» выбрали информатику?**

```
=СЧЁТЕСЛИМН(A2:A1001;"В";C2:C1001;"информатика")
```

**2. Средний балл учеников округа «Ю»?**

```
=СРЗНАЧЕСЛИ(A2:A1001;"Ю";D2:D1001)
```

**3. Сколько учеников набрали больше 600 баллов?**

```
=СЧЁТЕСЛИ(D2:D1001;">600")
```

**4. Вычислить в каждой строке новое значение** (например стоимость = количество × цена), затем просуммировать по условию:

```
E2:  =C2*D2            ← протянуть вниз
H3:  =СУММЕСЛИ(A2:A1001;"Южный";E2:E1001)
```

**5. Условие «ИЛИ» внутри строки** — вспомогательный столбец:

```
F2:  =ЕСЛИ(ИЛИ(B2<5;C2<5);1;0)      ← протянуть вниз
H2:  =СУММ(F2:F1001)
```

**6. Работа с датами** («средняя температура в мае»): вспомогательный столбец с номером месяца:

```
G2:  =МЕСЯЦ(A2)        ← протянуть вниз
H2:  =СРЗНАЧЕСЛИ(G2:G366;5;B2:B366)
```

> [!TIP]
> Вспомогательные столбцы — это нормально. Главное, чтобы ответы оказались в ячейках, указанных в задании (обычно H2, H3), а данные в исходных столбцах **не были испорчены**.

## Точность ответа

«С точностью не менее двух знаков после запятой» — оставьте формулу как есть: она хранит много знаков. Если хотите, увеличьте число отображаемых знаков кнопкой «Добавить десятичный знак». **Не округляйте до целых!**

## Сортировка и фильтр

- **Сортировка**: Данные → Сортировка. Выделяйте **всю таблицу**, иначе строки «разъедутся».
- **Автофильтр**: Данные → Автофильтр (в Excel: Данные → Фильтр). Удобен, чтобы *посмотреть* данные. Считать лучше формулами: в Calc функция `СЧЁТЕСЛИ` считает и скрытые строки.

## Диаграммы

Для круговой диаграммы нужна маленькая таблица: подписи и значения. Посчитайте значения формулами в свободном месте:

| | J | K |
|---|---|---|
| 1 | ЮВ | `=СЧЁТЕСЛИ(A2:A1001;"ЮВ")` |
| 2 | СЗ | `=СЧЁТЕСЛИ(A2:A1001;"СЗ")` |
| 3 | СВ | `=СЧЁТЕСЛИ(A2:A1001;"СВ")` |

### LibreOffice Calc

1. Выделите `J1:K3`.
2. **Вставка → Диаграмма…**
3. Тип: **Круговая**. Нажмите **Далее**.
4. Диапазон данных: «Ряды данных в столбцах», «Первый столбец как подпись».
5. На шаге «Элементы диаграммы» поставьте **«Показать легенду»**.
6. **Готово.** Затем правой кнопкой по диаграмме → **Вставить подписи данных** (показать значение).
7. Перетащите диаграмму так, чтобы левый верхний угол был у ячейки из задания (например, G6).

### Excel

1. Выделите `J1:K3`.
2. **Вставка → Круговая диаграмма**.
3. **Конструктор диаграмм → Добавить элемент → Подписи данных** и **Легенда**.
4. Перетащите диаграмму к нужной ячейке.

Пример результата:

![Пример круговой диаграммы](../images/theory/pie-example.png)

> [!IMPORTANT]
> Обязательные элементы по критериям: правильный **тип** диаграммы, **легенда**, **числовые значения** (подписи данных), правильные данные. Без подписей значений диаграмму не засчитают.

## Сохранение

Сохраните файл в формате, который требует задание (на экзамене — `.ods`, имя скажет организатор). В Calc: **Файл → Сохранить как**, тип «Электронная таблица ODF (.ods)».
