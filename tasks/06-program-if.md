**Что проверяют:** умение формально исполнять алгоритм, записанный на языке программирования (ветвление с составным условием).

## Что нужно знать

- Программа дана сразу на нескольких языках (Паскаль, Python, C++, Алгоритмический язык, иногда Бейсик). Читайте **Python**: он тебе знаком.
- Вся суть в строке `if …:` — условие с `and` / `or` / `not`.
- Программу запускают 9 раз с разными парами (s, t). Нужно посчитать, сколько раз будет «YES» (или «NO»), либо найти параметр A.

## Разбор 1. Сколько раз «YES»

> ```python
> s = int(input())
> t = int(input())
> if s > 10 or t > 10:
>     print("YES")
> else:
>     print("NO")
> ```
>
> Было проведено 9 запусков программы, при которых в качестве значений переменных s и t вводились следующие пары чисел:
> (1, 2), (11, 2), (1, 12), (11, 12), (−11, −12), (−11, 12), (−12, 11), (10, 10), (10, 5).
>
> Сколько было запусков, при которых программа напечатала «YES»?

Таблица — самый надёжный способ:

| (s, t) | s > 10 | t > 10 | ИЛИ |
|---|---|---|---|
| (1, 2) | 0 | 0 | 0 |
| (11, 2) | 1 | 0 | **1** |
| (1, 12) | 0 | 1 | **1** |
| (11, 12) | 1 | 1 | **1** |
| (−11, −12) | 0 | 0 | 0 |
| (−11, 12) | 0 | 1 | **1** |
| (−12, 11) | 0 | 1 | **1** |
| (10, 10) | 0 | 0 | 0 |
| (10, 5) | 0 | 0 | 0 |

**Ответ:** 5.

> [!TIP]
> Для `or` удобнее считать «NO»: оно бывает, только когда **обе** части ложны. Для `and` наоборот: «YES» только когда **обе** части истинны.

## Разбор 2. Параметр A

> ```python
> s = int(input())
> t = int(input())
> A = int(input())
> if s > A or t > 12:
>     print("YES")
> else:
>     print("NO")
> ```
>
> Пары (s, t): (13, 2), (11, 12), (−12, 12), (2, −2), (−10, −10), (6, −5), (2, 8), (9, 10), (1, 13).
>
> Укажите **наименьшее** целое значение параметра A, при котором для указанных входных данных программа напечатает «NO» **шесть** раз.

1. «NO» печатается, когда **s ≤ A и t ≤ 12**.
2. Пара (1, 13): t = 13 > 12 → всегда «YES». Остальные 8 пар имеют t ≤ 12.
3. Для этих 8 пар «NO» ⇔ s ≤ A. Значения s по возрастанию: **−12, −10, 2, 2, 6, 9, 11, 13**.
4. Шесть «NO» — это шесть самых маленьких s: −12, −10, 2, 2, 6, **9**. Значит, A ≥ 9, но A < 11 (иначе «NO» станет больше).
5. Наименьшее A = **9**.

> [!TIP]
> Общий приём: **выпишите значения переменной, которая сравнивается с A, отсортируйте** и посмотрите, где должна пройти граница.

## Ловушки

> [!WARNING]
> - `s > A` и `s >= A` дают разные границы. Обращайте внимание на знак.
> - Отрицательные числа: −12 < −10.
> - Вопрос про «NO», а вы считали «YES» (или наоборот).
> - `not (s < 5)` — это `s >= 5`.
