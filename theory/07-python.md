# Python для ОГЭ

> Нужна для заданий: [6 — чтение программ](../tasks/06-program-if.md), [16 — своя программа](../tasks/16-programming.md). Пригодится для самопроверки в [10](../tasks/10-number-systems.md), [11, 12](../tasks/12-file-masks.md).

Python ты уже знаешь хорошо, поэтому здесь только то, что нужно на экзамене, и типичные ловушки.

## Минимальный набор

```python
n = int(input())          # одно целое число в строке
a, b = map(int, input().split())   # два числа в одной строке (на ОГЭ обычно каждое в своей строке)

x % 10        # последняя цифра
x // 10       # число без последней цифры
x % k == 0    # x делится на k
x % 2 == 1    # нечётное (для натуральных)
10 <= x <= 99 # двузначное (натуральное)
abs(x)        # модуль

print(s)               # вывод
print(f"{avg:.1f}")    # вывод с одним знаком после запятой
```

> [!IMPORTANT]
> На ОГЭ **каждое число вводится в отдельной строке**. Читай `int(input())` по одному. Не надо `split()`, если в условии так не сказано.

## Два формата входных данных в задании 16

### 1. Сначала количество, потом числа

```python
n = int(input())
for i in range(n):
    x = int(input())
    ...
```

### 2. Числа до нуля (0 — признак конца, сам 0 не обрабатывается)

```python
x = int(input())
while x != 0:
    ...
    x = int(input())
```

Другой вариант записи, тоже верный:

```python
while True:
    x = int(input())
    if x == 0:
        break
    ...
```

## Шаблоны (выучить как таблицу умножения)

| Что найти | Начальное значение | Действие в цикле |
|---|---|---|
| Количество подходящих | `count = 0` | `count += 1` |
| Сумма подходящих | `s = 0` | `s += x` |
| Максимум подходящих | `mx = 0`* или `-30001` | `if x > mx: mx = x` |
| Минимум подходящих | `mn = 30001` | `if x < mn: mn = x` |
| Среднее | `s = 0`, `count = 0` | в конце `s / count` |
| Есть ли хоть одно | `found = False` | `found = True` |

\* `mx = 0` годится, только если все числа **натуральные**. Если числа могут быть отрицательными, начальное значение — число меньше любого возможного (например `-30001`), или первое введённое число.

### Пример полного решения

> Найти максимальное число, кратное 5 и оканчивающееся на 0 (числа вводятся до 0).

```python
mx = 0
x = int(input())
while x != 0:
    if x % 10 == 0 and x > mx:   # кратно 5 и оканчивается на 0 = оканчивается на 0
        mx = x
    x = int(input())
print(mx)
```

## Что проверяют эксперты в задании 16

Программу запускают на нескольких тестах (обычно 4). **2 балла** — программа выдаёт верный ответ на всех тестах; **1 балл** — ошибается ровно на одном тесте; **0** — во всех остальных случаях.

Чтобы не терять баллы:

- выводи **только ответ**, без пояснений: `print(count)`, а не `print("Ответ:", count)`;
- не пиши подсказки в `input("Введите число: ")`, лишний текст может сбить проверку;
- проверь «крайние» случаи: одно число, все числа подходят, ни одно не подходит (если такое возможно по условию);
- если в условии сказано «гарантируется, что есть хотя бы одно…», обрабатывать отсутствие не нужно.

## Самопроверка на компьютере

Чтобы не вводить числа руками каждый раз, сохрани тест в файл `test.txt` и запусти:

```
python program.py < test.txt
```

Или временно подставь список:

```python
data = iter([5, 12, 15, 7, 20, 3])   # n = 5, затем числа
input = lambda: str(next(data))      # ТОЛЬКО для проверки, перед сдачей удалить!
```

## Частые ошибки

> [!WARNING]
> - В формате «до нуля» обработали сам 0 (например, посчитали его как чётное число).
> - Забыли второй `x = int(input())` в конце цикла `while`: программа зациклится.
> - Для минимума начали с `mn = 0`: минимум всегда будет 0.
> - Перепутали `=` и `==`.
> - Неправильные отступы: `print` оказался внутри цикла.
> - «Оканчивается на 3»: `x % 10 == 3`, а не `x % 3 == 0`.
> - Для **отрицательных** чисел последняя цифра — `abs(x) % 10`: в Python `-13 % 10 == 7`.
