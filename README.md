# Подготовка к ОГЭ по информатике

Библиотека материалов для самостоятельной подготовки и для работы с учителем. Здесь все темы и все 16 заданий экзамена в формате 2026 года, план занятий на учебный год, 10 полных тренировочных вариантов и учебные файлы для заданий на компьютере.

> **Экзамен:** 16 заданий · 150 минут · максимум 21 балл · «5» от 17 баллов.
> Подробно — в разделе [Об экзамене](guide/exam.md).

## С чего начать

1. Прочитайте [Об экзамене](guide/exam.md): формат, баллы, стратегия.
2. Откройте [План подготовки](guide/plan.md): 33 недели по 1 часу, с октября по май.
3. Ведите [Чек-лист прогресса](guide/progress.md) и журнал ошибок.
4. Скачайте репозиторий (**Code → Download ZIP**): для заданий 11, 12, 14 нужны файлы из [`materials`](materials).

## Задания экзамена

Каждый файл устроен одинаково: что проверяют → что нужно знать → разбор типового задания → ловушки → 10 задач с ответами (5 авторских «для разминки» и 5 «как на экзамене»).

## Для учителя

- Ответы ко всем задачам скрыты под спойлерами `Ответ`; к вариантам есть [сводная таблица](variants/answers.md).
- Задачи 1–10 «как на экзамене», учебные файлы и варианты созданы генераторами в [`tools`](tools/README.md). Все ответы перепроверены независимым пересчётом: скрипт заново решает каждую задачу по тексту, исполняет программы из условий, считает пути по картинкам графов, файлы в каталоге и значения в таблицах.
- Эталонные решения для Робота проверены на 300 полях со случайными размерами, решения задания 16 — на 200 тестах.
- Можно сгенерировать новые задачи: см. [`tools/README.md`](tools/README.md).
