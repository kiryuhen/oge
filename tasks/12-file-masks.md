**Что проверяют:** умение искать файлы по маске имени и по свойствам (размер) средствами операционной системы.

**Теория:** [Файловая система и поиск файлов](../theory/10-files.md#задание-12-посчитать-файлы).

## Как это выглядит на экзамене

> Сколько файлов с расширением **.txt** содержится в подкаталогах каталога **Проза**? В ответе укажите только число.

Бывают вопросы про размер («объёмом более 50 Кбайт») и про общий объём файлов.

## Учебный каталог

Тренируйтесь на каталоге [`materials/archive`](../materials/archive): там 138 файлов разных типов в подкаталогах по годам. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.

## Разбор

> Сколько файлов с расширением **.png** содержится в каталоге **archive/photo** и всех его подкаталогах?

**Windows.** Открываем `archive\photo`, в строку поиска вводим `*.png`, ждём окончания поиска. Внизу окна: «Элементов: 3».

**Linux:**

```bash
find materials/archive/photo -type f -name "*.png" | wc -l
```

**Python:**

```python
import os
count = 0
for folder, _, files in os.walk("materials/archive/photo"):
    count += sum(1 for f in files if f.endswith(".png"))
print(count)
```

**Ответ:** 3.

### С условием на размер

> Сколько файлов **.jpg** объёмом **более 20 Кбайт** в каталоге **archive/photo**?

Windows: в строке поиска `*.jpg размер:>20КБ`, или вид «Таблица» → сортировка по столбцу «Размер», затем посчитать строки.

```bash
find materials/archive/photo -type f -name "*.jpg" -size +20k | wc -l
```

**Ответ:** 2.

> [!WARNING]
> **Кбайт = 1024 байта.** Проводник Windows показывает размер в КБ, округляя **вверх**: файл 20 481 байт он покажет как «21 КБ», а файл ровно 20 480 байт — как «20 КБ». Если файл на границе, откройте его **Свойства** и посмотрите точный размер в байтах.

## Ловушки

> [!WARNING]
> - Посчитали только файлы в самом каталоге, а нужно и в **подкаталогах** (или наоборот: «в подкаталогах» не включает файлы в самом каталоге).
> - Поиск захватил **папки**, подходящие под маску.
> - Маска `*.htm` в некоторых поисковиках находит и `.html`. Проверяйте расширения в результатах.
> - Не дождались окончания поиска.
