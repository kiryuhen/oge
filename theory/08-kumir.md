# КуМир: исполнитель Робот

> Нужна для задания: [15 — алгоритм для Робота](../tasks/15-robot.md).

С 2025 года задание 15 (Робот) и задание 16 (программа) **оба обязательные**: за них в сумме 4 балла. Робот проще, чем кажется: в нём всего 5 команд и 4 конструкции.

## Где писать

Среда **КуМир** (бесплатная, [скачать на сайте НИИСИ РАН](https://www.niisi.ru/kumir/)). Если на экзамене среды «Робот» нет, алгоритм записывают в текстовом файле `.txt` по тем же правилам.

Обстановка Робота задаётся в меню **Робот → Редактировать обстановку**. Нарисуй поле из условия, чтобы проверить алгоритм.

## Поле

- Клетчатое поле, между клетками могут быть **стены**.
- Робот стоит в одной клетке. Может закрашивать клетку, в которой стоит.
- Если Робот пойдёт в стену, он **разрушится**, и решение не засчитается.

## Команды

| Команда | Действие |
|---|---|
| `вверх` | на клетку вверх |
| `вниз` | на клетку вниз |
| `влево` | на клетку влево |
| `вправо` | на клетку вправо |
| `закрасить` | закрасить текущую клетку |

## Условия (проверки)

| Условие | Истинно, когда |
|---|---|
| `сверху свободно` | сверху нет стены |
| `снизу свободно` | снизу нет стены |
| `слева свободно` | слева нет стены |
| `справа свободно` | справа нет стены |
| `сверху стена` (и т. д.) | сверху есть стена |
| `клетка закрашена` | текущая клетка закрашена |
| `клетка чистая` | текущая клетка не закрашена |

Условия можно соединять: `и`, `или`, `не`. Пример: `справа свободно и сверху стена`.

```
использовать Робот

```

## Конструкции

### Цикл «пока» (главный инструмент)

```
нц пока сверху стена
  закрасить
  вправо
кц
```

Повторяет тело, **пока** условие истинно. Условие проверяется **перед** каждым повтором.

### Цикл «N раз»

```
нц 5 раз
  вправо
кц
```

На ОГЭ размеры стен **неизвестны**, поэтому `нц N раз` почти не нужен.

### Ветвление

```
если снизу стена то
  закрасить
все
```

```
если справа свободно то
  вправо
иначе
  вниз
все
```

> [!IMPORTANT]
> Ветвление обязательно закрывается словом `все`, цикл — словом `кц`.

## Как думать о задаче на Робота

1. **Разметь клетки, которые нужно закрасить**, на рисунке-примере.
2. Найди для каждого участка **условие, которое истинно, пока Робот идёт вдоль него**: «пока сверху стена», «пока справа стена», «пока снизу свободно».
3. Для каждого участка напиши цикл `нц пока … закрасить; шаг; кц`.
4. Подумай, где Робот окажется **после** цикла (обычно на клетку дальше конца стены), и как перейти к следующему участку.
5. **Проверь на поле другого размера**: стена длиной 1, очень длинная стена. Алгоритм должен работать для **любых** размеров.

### Где остановится цикл

```
нц пока сверху стена
  закрасить
  вправо
кц
```

Робот закрашивает клетку под стеной и шагает вправо. Когда он выйдет из-под стены, условие станет ложным, и цикл кончится. **Робот стоит на первой клетке после стены, и она НЕ закрашена.** Это очень важно для следующего шага.

> [!TIP]
> Порядок «закрасить, потом шаг» внутри цикла закрашивает все клетки вдоль стены. Порядок «шаг, потом закрасить» пропустит первую клетку и закрасит лишнюю после конца стены.

## Критерии оценивания задания 15

- **2 балла** — алгоритм правильно работает при всех допустимых исходных данных.
- **1 балл** — при всех допустимых исходных данных Робот не разбивается, выполнение завершается, количество неправильно закрашенных или незакрашенных клеток **не превышает 10**.
- **0 баллов** — в остальных случаях (разбился, зациклился, много ошибок).

Отсюда стратегия: даже если не уверен в идеальном решении, напиши алгоритм, который **точно не разобьёт Робота**. Это уже шанс на 1 балл.

## Частые ошибки

> [!WARNING]
> - Ведёт Робота в стену. Перед каждым шагом в сторону стены спроси себя: «А там точно свободно?»
> - Использует `нц 7 раз` по рисунку: на другом поле размер будет другим.
> - Забыл закрасить угловую клетку, где одна стена переходит в другую.
> - Перепутал `сверху` и `снизу` у горизонтальной стены. Направления всегда считаются **по экрану**: `вверх` — к верхнему краю поля. У Робота нет «своей» стороны, он не поворачивается.
> - Бесконечный цикл: условие никогда не становится ложным (например, `нц пока справа свободно` на бесконечном поле без стен).
