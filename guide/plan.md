# План подготовки: 1 час в неделю

Старт — неделя 5 октября 2026 года, финиш — конец мая 2027 года (33 недели). Точная дата экзамена появится в расписании ОГЭ зимой, обычно это конец мая или начало июня.

> [!IMPORTANT]
> **Честно о времени.** 33 часа хватит, чтобы пройти все темы и решить варианты по частям. Для цели «максимум» в последние 6–8 недель **очень желательно добавить время**: полный вариант идёт 2,5 часа, и его хотя бы 2–3 раза нужно решить целиком, в реальном темпе. Хороший момент — весенние и майские каникулы.

## Как устроено одно занятие (60 минут)

Каждый файл задания — подробный гайд: **карта подтипов → главная идея → разбор каждого подтипа (реальная задача из банка, несколько способов, проверка за 30 секунд) → тренировка по подтипу → смешанная тренировка**.

| Минуты | Что делаем |
|---|---|
| 0–10 | Повторить ошибки прошлого занятия (по [чек-листу прогресса](progress.md)) |
| 10–25 | Теория и «Главная идея» гайда, разбор первого подтипа |
| 25–50 | Подтипы недели (см. таблицу ниже): разбор → 2–4 тренировочные задачи на каждый |
| 50–55 | Смешанная тренировка (если есть время) |
| 55–60 | Отметить результат в [чек-листе](progress.md), выписать ошибки |

## Если что-то пошло не так

- **Пропустили неделю** — используйте резервные недели 13–14 или сдвиньте блок 4 (вариантов больше, чем недель).
- **Тема не идёт** — перечитайте «Главную идею» гайда, решите тренировку по подтипу ещё раз, затем [задачи из открытого банка ФИПИ](https://oge.fipi.ru/bank/).
- **Всё идёт легко** — решайте варианты целиком раньше, чем по плану.
