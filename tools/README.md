# Инструменты

Скрипты, которыми сгенерированы задачи, учебные материалы и картинки библиотеки, и проверка ответов. Ученику они не нужны. Они пригодятся учителю, чтобы сделать новые задачи или убедиться, что ответы верные.

Требования: Python 3.10+, `pip install openpyxl pillow matplotlib`, Graphviz (`dot`); для задания 13 — Chromium.

| Скрипт | Что делает |
|---|---|
| `gen_tasks.py` | генераторы заданий 1–10 в формате ФИПИ (ответы вычисляются) |
| `subtypes.py` | генераторы по подтипам заданий 1–10 (36 подтипов) для гайдов |
| `robot.py` | интерпретатор подмножества КуМир для Робота и рисовалка полей |
| `robot_tasks.py` | банк задач 15 с эталонными решениями; проверка на 300 случайных полях каждой |
| `prog_tasks.py` | банк задач 16 с эталонными решениями и тестами |
| `build_corpus.py` | каталог `materials/archive` (задания 11, 12) и вопросы к нему |
| `build_xlsx.py` | таблицы `materials/task14/*.xlsx` и вопросы к ним |
| `build_13.py` | образцы документов и требования к презентациям (задание 13) |
| `build_images.py` | иллюстрации к теории и разборам |
| `build_practice.py` | вставляет тренировочные задачи в `tasks/*.md`: общий блок (`BEGIN/END:generated`) и блоки подтипов (`BEGIN/END:sub:N.K`) |
| `build_variants.py` | собирает `variants/*.md` и сводную таблицу ответов |
| `verify_all.py` | **независимая проверка**: заново решает все задачи по тексту `.md`-файлов другим способом; алгоритмы и программы, помеченные в гайдах `<!-- robot:rNN -->` и `<!-- prog:pNN -->`, прогоняет на соответствующих задачах |

## Пересборка всего

Из корня репозитория:

```bash
python3 tools/build_corpus.py
python3 tools/build_xlsx.py
python3 tools/build_13.py
python3 tools/build_images.py
python3 tools/robot_tasks.py
cd tools && python3 build_practice.py && python3 build_variants.py && cd ..
python3 tools/verify_all.py
```

Генерация детерминирована (фиксированные зёрна), поэтому повторный запуск даёт те же задачи. Чтобы получить новые задачи, поменяйте зёрна в `build_practice.py` и `build_variants.py`.
