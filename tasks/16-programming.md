## Разбор

> Напишите программу, которая в последовательности натуральных чисел определяет сумму чисел, кратных 7 и оканчивающихся на 3. Программа получает на вход количество чисел в последовательности, а затем сами числа. В последовательности всегда имеется хотя бы одно число, кратное 7 и оканчивающееся на 3. Количество чисел не превышает 100. Введённые числа не превышают 300. Программа должна вывести одно число — сумму чисел, кратных 7 и оканчивающихся на 3.
>
> **Пример работы программы:**
>
> | Входные данные | Выходные данные |
> |---|---|
> | 3<br>63<br>14<br>33 | 63 |

### Шаг 1. Формат ввода

«Сначала количество, потом числа», значит, цикл `for` на n повторений, и каждое число читаем `int(input())`.

### Шаг 2. Условие

«Кратно 7» — `x % 7 == 0`; «оканчивается на 3» — `x % 10 == 3`; оба сразу — `and`.

### Шаг 3. Что накапливаем

Сумму: `s = 0` до цикла, `s += x` внутри.

### Решение

```python
n = int(input())
s = 0
for i in range(n):
    x = int(input())
    if x % 7 == 0 and x % 10 == 3:
        s += x
print(s)
```

### Шаг 4. Тесты (как у экспертов)

| № | Входные данные | Ожидаемый вывод | Что проверяет |
|---|---|---|---|
| 1 | 3, 63, 14, 33 | 63 | пример из условия |
| 2 | 4, 133, 63, 7, 23 | 196 | несколько подходящих чисел |
| 3 | 2, 203, 703 | 203 | число 703 оканчивается на 3, но не кратно 7 |
| 4 | 5, 63, 63, 1, 3, 273 | 399 | повторяющиеся числа считаются каждое |

> [!TIP]
> Придумывайте тесты на **ловушки условия**: число подходит по одному признаку, но не по другому; одинаковые числа; самое маленькое и самое большое число.

## Если числа вводятся до нуля

```python
s = 0
x = int(input())
while x != 0:
    if x % 7 == 0 and x % 10 == 3:
        s += x
    x = int(input())
print(s)
```

## Ловушки

> [!WARNING]
> - **Лишний вывод:** `print("Сумма:", s)` или `input("Введите n")`. Выводи только ответ.
> - **Сам ноль** в формате «до нуля» не должен обрабатываться.
> - **Начальное значение минимума** — не 0, а число больше любого возможного (например 30001), иначе ответ всегда 0.
> - **Максимум среди отрицательных**: если числа могут быть отрицательными, `mx = 0` даст неверный ответ.
> - **Среднее**: делить на количество **подходящих** чисел, а не на n. Формат вывода — как в условии (`f"{avg:.1f}"`).
> - **Ввод в одну строку**: на ОГЭ каждое число — с новой строки. `input().split()` здесь не нужен.
