# Интернет: адреса и поисковые запросы

> Нужна для заданий: [7 — адрес файла (URL)](../tasks/07-url.md), [8 — поисковые запросы](../tasks/08-search-queries.md).

## Компьютерные сети (кратко)

- **Локальная сеть** — компьютеры в одном здании; **глобальная** — по всему миру (Интернет).
- **Сервер** хранит данные и отвечает на запросы, **клиент** (браузер) их запрашивает.
- **Протокол** — правила обмена данными.

| Протокол | Для чего |
|---|---|
| `http` | передача веб-страниц |
| `https` | то же, но с шифрованием |
| `ftp` | передача файлов |

## Доменные имена

Имя сервера состоит из частей через точку и читается **справа налево** от общего к частному:

```
     school . edu . ru
     ──┬──   ─┬─   ┬─
       │      │    └── домен верхнего уровня (страна или тип: ru, com, org, net)
       │      └─────── домен второго уровня
       └────────────── имя сервера / поддомен
```

## URL — адрес файла в Интернете

```
https://school.edu.ru/docs/plan.pdf
──┬──  ─┬─  ─────┬─────  ───────┬──────
  │     │        │              └── путь к файлу (каталоги и имя файла)
  │     │        └── имя сервера
  │     └── разделитель «://»
  └── протокол
```

Общая схема: **протокол :// сервер / каталог / файл**.

### Задание 7

Фрагменты адреса перемешаны и обозначены буквами. Например:

> Файл **rus.doc** на сервере **obr.org**, протокол **https**.
> А) `obr.` Б) `/` В) `org` Г) `://` Д) `doc` Е) `rus.` Ж) `https`

Собираем адрес: `https` `://` `obr.` `org` `/` `rus.` `doc` → **ЖГАВБЕД**.

> [!TIP]
> Алгоритм всегда одинаковый: **протокол → :// → сервер → / → файл**. Сначала выпишите полный адрес словами, потом заменяйте фрагменты буквами.

> [!WARNING]
> - Точка «приклеена» к фрагменту: `obr.` и `rus.`. Отдельной точки не ищите.
> - Фрагменты могут совпадать по виду с другими частями (например, сервер `ftp.net` и протокол `ftp`). Определяйте по смыслу, где какой.

## Поисковые запросы и круги Эйлера

В языке запросов:

| Символ | Операция | Что найдёт |
|---|---|---|
| `&` | И | страницы, где есть **оба** слова (пересечение) |
| `\|` | ИЛИ | страницы, где есть **хотя бы одно** слово (объединение) |

Поэтому по запросу `A | B` всегда найдено **не меньше**, чем по `A`, а по `A & B` — **не больше**, чем по `A`.

### Два слова

![Круги Эйлера для двух множеств](../images/theory/euler-2.svg)

Обозначим области: 1 — только A, 2 — A и B, 3 — только B. Тогда:

| Запрос | Области |
|---|---|
| A | 1 + 2 |
| B | 2 + 3 |
| A & B | 2 |
| A \| B | 1 + 2 + 3 |

Главная формула:

$$|A \mid B| = |A| + |B| - |A \mathbin{\&} B|$$

Отсюда легко выразить любую величину, если три известны. Например:

$$|B| = |A \mid B| - |A| + |A \mathbin{\&} B|$$

> [!TIP]
> Вместо формул удобно рисовать круги и подписывать числа в каждой **области**. Сначала заполните пересечение, затем остальное.

### Пример

| Запрос | Найдено (тыс.) |
|---|---|
| Крейсер \| Линкор | 7000 |
| Крейсер & Линкор | 800 |
| Крейсер | 4800 |

Сколько найдётся по запросу **Линкор**?

- Только «Крейсер»: 4800 − 800 = 4000.
- Только «Линкор»: 7000 − 4800 = 2200.
- Линкор = только Линкор + оба = 2200 + 800 = **3000**.

Проверка по формуле: 4800 + 3000 − 800 = 7000 ✓.

### Три слова

![Круги Эйлера для трёх множеств](../images/theory/euler-3.svg)

Пронумеруйте 7 областей и для каждого запроса выпишите, из каких областей он складывается. Часто в условии сказано, что какие-то слова **не встречаются вместе**: тогда соответствующие области равны 0, и задача сводится к двум кругам.

Пример: «Пушкин & Лермонтов = 0» → области 2 и 5 пустые.
