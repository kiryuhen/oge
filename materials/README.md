# Учебные материалы для заданий на компьютере

На экзамене к заданиям 11–14 выдают файлы. Здесь их тренировочные аналоги.

| Каталог | Для задания | Что внутри |
|---|---|---|
| [`archive`](archive) | [11](../tasks/11-search-in-files.md), [12](../tasks/12-file-masks.md) | «Архив школьной газеты»: 73 статьи (`.txt`, `.htm`) по годам и выпускам, фотографии (`.jpg`, `.png`), таблицы (`.csv`) — всего 138 файлов |
| [`task14`](task14) | [14](../tasks/14-spreadsheets.md) | таблицы `.xlsx` на 365–1000 строк: `example` — для разбора, `practice-1…4` — тренировка, `variant-01…10` — для вариантов |

Все тексты, имена и данные **вымышленные** и сгенерированы программой ([`tools`](../tools)), поэтому ответы известны точно.

**Как скачать:** на главной странице репозитория нажмите **Code → Download ZIP** и распакуйте архив. Таблицы `.xlsx` открываются и в LibreOffice Calc, и в Excel. На экзамене будет формат `.ods`: сохраняйте результат через **Файл → Сохранить как → .ods**, чтобы привыкнуть.
