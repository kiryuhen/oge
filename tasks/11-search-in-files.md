## Как это выглядит на экзамене

Вам дают каталог с файлами — обычно это литературные произведения (папки «Проза», «Поэзия» и т. п.). Реальные формулировки из открытого банка:

> С помощью текстового редактора определите, какой правитель кажется «жалок и смешон» Казарину, герою драмы М. Ю. Лермонтова «Маскарад». В ответе укажите имя. Текст указанного произведения представлен **в различных формах** в одном из подкаталогов каталога.
>
> *№ 12860 в каталоге «Решу ОГЭ».*

> В одном из произведений Н. В. Гоголя, текст которого приведён в подкаталоге каталога Проза, есть описание строения, которое автор называет «Храм уединённого размышления». С помощью поисковых средств операционной системы и текстового редактора или браузера выясните название деревни, в которой расположено строение.
>
> *№ 35589 в каталоге «Решу ОГЭ».*

Ответ — **одно слово** из текста рядом с найденной фразой.

Все подтипы решаются одинаково. Различаются только тем, **по какому слову искать** и **что выписать в ответ**.

## Главная идея: искать нужно по самому редкому слову

Поиск находит **все** файлы, где встречается слово. Чем слово обычнее, тем больше лишних результатов. Поэтому:

1. Выпишите из вопроса слова, которые **точно** есть в тексте: цитату, имя героя, необычное название.
2. Выберите **самое редкое** — именно его ищите. «Храм уединённого размышления» лучше, чем «деревня»; «Казарин» лучше, чем «правитель».
3. Ищите по **основе** слова (`Казарин`, а не `Казарину`): так найдутся все падежи.

> [!WARNING]
> Буквы **е** и **ё**. В вопросе может стоять «уединённого», а в тексте «уединенного» (или наоборот). Если поиск ничего не нашёл, уберите из запроса слова с «ё» или «е»-«ё».

### Почему текст бывает «в различных формах»

Один и тот же текст может лежать в нескольких файлах: `.txt`, `.docx`, `.odt`, `.htm`, `.pdf`. Поиск ОС может найти не все из них (сжатые форматы не всегда индексируются). Достаточно найти фразу **в любом** из файлов.

## Три способа поиска

### Способ 1. Поиск ОС по содержимому файлов

- **Windows:** откройте нужный каталог, в строке поиска введите `содержимое:Казарин` (англ. `content:`). Дождитесь окончания поиска.
- **Linux (Альт, Astra, РЕД ОС):** в файловом менеджере `Ctrl+F` и поиск по содержимому (в Dolphin — «Искать в содержимом»).

### Способ 2. Открыть файлы и искать в редакторе

Если файлов мало (5–10), откройте их по очереди в текстовом редакторе или браузере и нажмите `Ctrl+F`. Надёжно для любых форматов, включая `.docx` и `.pdf`.

### Способ 3. Командная строка или Python

```bash
grep -ril "казарин" .          # какие файлы содержат слово (без учёта регистра)
grep -rin "казарин" .          # сами строки с номерами
```

```python
import os
phrase = "Казарин"
for folder, _, files in os.walk("."):
    for name in files:
        if name.endswith((".txt", ".htm", ".html")):
            path = os.path.join(folder, name)
            text = open(path, encoding="utf-8", errors="ignore").read()
            if phrase in text:
                print(path)
```

> [!NOTE]
> `grep` и Python не видят текст внутри `.docx`, `.odt` и `.pdf`: эти форматы сжаты. Для них используйте способы 1 и 2.

## Подтип 11.2. Где или что? (место, предмет, название)

*Частота: часто.*

### Как решать

1. Ищите по **уникальной детали** из условия: имени организатора, числу, цитате.
2. Ответ часто стоит **в соседнем предложении**, а не в том же. Читайте весь абзац.
3. Записывайте название так, как оно стоит в тексте, если в условии не сказано иначе.

Пример из банка (№ 35589): по фразе «Храм уединённого размышления» находим главу «Мёртвых душ», где описано имение Манилова. Название деревни — в начале того же описания.

### Проверка за 30 секунд

Найдите ответ поиском ещё раз и убедитесь, что он стоит **рядом** с исходной деталью, а не в другом эпизоде того же файла.

## Подтип 11.3. Какое слово? (характеристика, пропущенное слово)

*Частота: иногда.*

### Как решать

Если в вопросе цитата с пропуском, ищите **часть цитаты без пропуска** — 2–3 слова подряд. Длинную цитату целиком искать не стоит: из-за переноса строки, лишнего пробела или другой кавычки она может не найтись.

### Проверка за 30 секунд

Вставьте найденное слово в цитату из вопроса и прочитайте её целиком: она должна совпасть с текстом.
