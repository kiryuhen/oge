## Главная идея: один проход и «накопители»

Числа приходят **по одному**, и хранить их все не нужно. Заводим переменные-накопители и обновляем их после каждого числа. Важно одно правило:

> **После обработки любого количества чисел накопитель должен содержать правильный ответ для уже прочитанной части последовательности.**

Отсюда начальные значения: это ответ для **пустой** последовательности.

| Что ищем | Начальное значение | Почему |
|---|---|---|
| количество | `0` | в пустой последовательности подходящих чисел 0 |
| сумма | `0` | сумма пустого набора 0 |
| максимум | меньше любого возможного числа (`-30001`) или первое число | любое настоящее число должно его «побить» |
| минимум | больше любого возможного числа (`30001`) | то же, в другую сторону |

> [!WARNING]
> `mx = 0` годится, **только если все числа натуральные**. Если числа могут быть отрицательными (а «целые числа» — могут), максимум из, например, −5 и −3 получится 0 — неверно.

### Почему последняя цифра — это `x % 10`, а в q-ичной системе — `x % q`

Любое число записывается как $x = 10 \cdot k + r$, где $r$ — последняя цифра. Поэтому `x % 10` — последняя цифра, а `x // 10` — число без неё. В системе с основанием $q$ точно так же: $x = q \cdot k + r$, и `x % q` — последняя цифра q-ичной записи.

### Способ 1. Классический цикл

```python
n = int(input())
count = 0
for i in range(n):
    x = int(input())
    if x % 6 == 0 and x % 10 == 4:   # кратно 6 и оканчивается на 4
```

### Способ 2. Собрать числа в список

Python позволяет сначала прочитать все числа, а потом посчитать одной строкой. Для ОГЭ это тоже верно:

```python
n = int(input())
a = [int(input()) for i in range(n)]
print(sum(1 for x in a if x % 6 == 0 and x % 10 == 4))
```

Способ 2 короче, но способ 1 проще отлаживать и переносить на формат «до нуля».

## Подтип 16.2. Максимум, минимум, два ответа

### Способ 1. Начальное значение «за пределами»

```python
mx = 0                      # числа натуральные, поэтому 0 меньше любого из них
x = int(input())
while x != 0:
    if x % 5 == 0 and x > mx:
        mx = x
    x = int(input())
print(mx)
```

### Способ 2. Флаг «ещё не было подходящих»

Когда границ нет или они неудобны, заведите флаг:

```python
mx = None
x = int(input())
while x != 0:
    if x % 5 == 0 and (mx is None or x > mx):
        mx = x
    x = int(input())
print(mx)
```

Этот способ работает для любых чисел, включая отрицательные.

### Два ответа

Если нужно вывести два числа (например, количество и максимум), считайте оба в **одном** цикле и выводите каждое отдельным `print`, в том порядке, что указан в условии.

## Подтип 16.3. Цифры и системы счисления

### Как выглядит (по разборам демоверсии 2026)

> Напишите программу, которая в последовательности натуральных чисел находит сумму чисел, которые в 7-ричной системе счисления оканчиваются на цифру 1. Программа получает на вход количество чисел в последовательности, а затем сами числа.

### Способ 1. Остаток от деления на основание

«Оканчивается на 1 в 7-ричной записи» ⇔ `x % 7 == 1` (см. главную идею).

<!-- prog:p21 -->
```python
n = int(input())
s = 0
for i in range(n):
    x = int(input())
```

### Способ 2. Честный перевод в 7-ричную запись (для проверки)

```python
def last_digit(x, q):
    digits = ""
    while x > 0:
        digits = str(x % q) + digits
        x //= q
    return digits[-1]

print(last_digit(50, 7))   # 50 = 101₇ → «1»
```

Так проверяют себя, но на экзамене достаточно способа 1: короче — меньше ошибок.

| Условие | Код |
|---|---|
| оканчивается на 7 | `x % 10 == 7` |
| двузначное | `10 <= x <= 99` |
| вторая цифра с конца равна 3 | `x // 10 % 10 == 3` |
| оканчивается на 7 в 8-ричной записи | `x % 8 == 7` |

## Подтип 16.4. Форматы ввода и отрицательные числа

### Три формата ввода

| Условие | Цикл |
|---|---|
| «сначала количество, потом числа» | `n = int(input())` · `for i in range(n):` |
| «последовательность заканчивается числом 0» | `x = int(input())` · `while x != 0:` · … · `x = int(input())` |
| «введите 5 чисел» | `for i in range(5):` |

Для формата «до нуля» есть два равноправных способа:

```python
x = int(input())          # способ 1: читаем до цикла и в конце цикла
while x != 0:
    ...
    x = int(input())
```

```python
while True:               # способ 2: бесконечный цикл с выходом
    x = int(input())
    if x == 0:
        break
    ...
```

### Отрицательные числа и `%`

В Python остаток всегда **неотрицательный**: `-13 % 10 == 7`, а не 3. Поэтому для «целых чисел»:

| Условие | Неверно | Верно |
|---|---|---|
| оканчивается на 4 | `x % 10 == 4` (−14 не пройдёт: `-14 % 10 == 6`) | `abs(x) % 10 == 4` |
| нечётное | `x % 2 == 1` — для Python **верно** (`-3 % 2 == 1`) | можно и `x % 2 != 0` |
| кратно 3 | `x % 3 == 0` — верно и для отрицательных | |

<!-- prog:p24 -->
```python
count = 0
x = int(input())
while x != 0:
    if abs(x) % 10 == 4:
        count += 1
    x = int(input())
print(count)
```
