# Задание 10. Системы счисления

| Часть | Ответ | Балл | Время на экзамене | Сложность |
|---|---|---|---|---|
| 1 (без компьютера) | число | 1 | 2–4 мин | базовая |

**Что проверяют:** знание позиционных систем счисления: перевод чисел и сравнение чисел в разных системах.

**Теория:** [Системы счисления](../theory/03-number-systems.md).

## Что нужно знать

- Перевод в десятичную: $a_n \dots a_1 a_0 = a_n \cdot q^n + \dots + a_1 \cdot q + a_0$.
- Степени: $2^0 \dots 2^{10}$ = 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024; $8^2 = 64$, $8^3 = 512$; $16^2 = 256$.
- Шестнадцатеричные цифры: A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.

## Разбор

> Среди приведённых ниже трёх чисел, записанных в различных системах счисления, найдите максимальное и запишите его в ответе в десятичной системе счисления. В ответе запишите только число, основание системы счисления указывать не нужно.
>
> $23_{16}$, $32_8$, $11110_2$

- $23_{16} = 2 \cdot 16 + 3 = 35$
- $32_8 = 3 \cdot 8 + 2 = 26$
- $11110_2 = 16 + 8 + 4 + 2 = 30$

**Ответ:** 35.

> [!TIP]
> Пишите рядом с каждым числом его десятичное значение — потом сравнивать легко. Ответ — **десятичное** значение максимального (или минимального) числа, а не его запись в исходной системе.

## Другие формулировки

| Формулировка | Как решать |
|---|---|
| «Переведите число 135 в двоичную систему. Сколько единиц в записи?» | 135 = 128 + 4 + 2 + 1 → 10000111 → **4** единицы |
| «Сколько значащих нулей?» | Нули в записи **без** ведущих: 10000111 → **4** нуля |
| «Переведите $1011011_2$ в десятичную» | 64 + 16 + 8 + 2 + 1 = **91** |

## Ловушки

> [!WARNING]
> - Ответ записан в исходной системе (например, `23` вместо `35`).
> - Разряды пронумерованы слева направо. Номер разряда считается **справа**, начиная с 0.
> - В двоичной записи пропустили разряд. Пишите степени двойки над цифрами.

### Задача 1

Найдите **максимальное** из чисел $1100110_2$, $147_8$, $65_{16}$ и запишите его в десятичной системе.

<details><summary>Ответ</summary>

**103**

$1100110_2 = 64 + 32 + 4 + 2 = 102$; $147_8 = 64 + 32 + 7 = 103$; $65_{16} = 96 + 5 = 101$.

</details>

### Задача 2

Найдите **минимальное** из чисел $23_{16}$, $42_8$, $100100_2$ и запишите его в десятичной системе.

<details><summary>Ответ</summary>

**34**

$23_{16} = 35$; $42_8 = 34$; $100100_2 = 32 + 4 = 36$.

</details>

### Задача 3

Сколько единиц в двоичной записи числа 173?

<details><summary>Ответ</summary>

**5**

173 = 128 + 32 + 8 + 4 + 1 → $10101101_2$.

</details>

### Задача 4

Сколько значащих нулей в двоичной записи числа 128?

<details><summary>Ответ</summary>

**7**

$128 = 2^7 = 10000000_2$: единица и семь нулей.

</details>

### Задача 5

Какое из чисел **не равно** остальным: $17_8$, $1111_2$, $\text{E}_{16}$, $15_{10}$? Запишите его десятичное значение.

<details><summary>Ответ</summary>

**14**

$17_8 = 15$, $1111_2 = 15$, $\text{E}_{16} = 14$. Отличается $\text{E}_{16} = 14$.

</details>
