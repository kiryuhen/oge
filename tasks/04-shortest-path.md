# Задание 4. Кратчайший путь по таблице

| Часть | Ответ | Балл | Время на экзамене | Сложность |
|---|---|---|---|---|
| 1 (без компьютера) | число | 1 | 3–5 мин | базовая |

**Что проверяют:** умение анализировать формальные описания реальных объектов: таблицу расстояний между пунктами.

**Теория:** [Графы, таблицы, схемы](../theory/05-graphs.md).

## Что нужно знать

- Таблица симметрична: число на пересечении строки A и столбца B — длина дороги A–B. Пусто — дороги нет.
- Сначала **рисуем граф**, потом ищем путь.
- Самый короткий путь — не обязательно путь с меньшим числом дорог!

## Разбор

> Между населёнными пунктами A, B, C, D, E построены дороги, протяжённость которых (в километрах) приведена в таблице.
>
> |   | A | B | C | D | E |
> |---|---|---|---|---|---|
> | **A** |  | 2 | 5 |  |  |
> | **B** | 2 |  | 2 | 7 |  |
> | **C** | 5 | 2 |  | 3 | 9 |
> | **D** |  | 7 | 3 |  | 1 |
> | **E** |  |  | 9 | 1 |  |
>
> Определите длину кратчайшего пути между пунктами A и E. Передвигаться можно только по дорогам, протяжённость которых указана в таблице.

**Шаг 1. Выписываем дороги** (только над диагональю, чтобы не повторяться):
A–B 2, A–C 5, B–C 2, B–D 7, C–D 3, C–E 9, D–E 1.

**Шаг 2. Рисуем граф** на черновике (зелёным выделен ответ, который мы сейчас найдём):

![Граф к разбору](../images/tasks/t04-example.svg)

**Шаг 3. Метод пометок** — расстояние от A до каждой вершины:

| Вершина | Как добраться | Расстояние |
|---|---|---|
| A | старт | 0 |
| B | A–B | 2 |
| C | min(A–C = 5; A–B–C = 2 + 2 = 4) | **4** |
| D | min(B–D = 2 + 7 = 9; C–D = 4 + 3 = 7) | **7** |
| E | min(C–E = 4 + 9 = 13; D–E = 7 + 1 = 8) | **8** |

**Ответ:** 8 (путь A → B → C → D → E).

> [!TIP]
> Двигайтесь «волной» от старта: сначала ближайшие вершины, потом следующие. Для каждой вершины записывайте **лучшее** найденное расстояние и откуда пришли.

## Варианты вопроса

| Формулировка | Как решать |
|---|---|
| «…кратчайшего пути между A и E» | метод пометок |
| «…проходящего через пункт C» | (кратчайший A → C) + (кратчайший C → E) |
| «…не проходящего через пункт D» | вычеркнуть D со всеми дорогами и искать заново |

## Ловушки

> [!WARNING]
> - Взяли прямую дорогу A–E и не проверили обходные пути.
> - Пропустили дорогу при переносе из таблицы на рисунок. Сверьте: число дорог = число заполненных клеток над диагональю.
> - Перепутали строку и столбец — в симметричной таблице это не страшно, но в задачах с **односторонними** дорогами важно.

### Задача 1

|   | A | B | C | D | E |
|---|---|---|---|---|---|
| **A** |  | 4 | 1 |  | 9 |
| **B** | 4 |  | 2 | 1 |  |
| **C** | 1 | 2 |  | 5 |  |
| **D** |  | 1 | 5 |  | 3 |
| **E** | 9 |  |  | 3 |  |

Найдите длину кратчайшего пути из A в E.

<details><summary>Ответ</summary>

**7**

A → C → B → D → E: 1 + 2 + 1 + 3 = 7. Прямая дорога A–E длиннее (9).

</details>

### Задача 2

|   | A | B | C | D | E |
|---|---|---|---|---|---|
| **A** |  | 3 |  | 2 |  |
| **B** | 3 |  | 4 |  | 6 |
| **C** |  | 4 |  | 6 | 1 |
| **D** | 2 |  | 6 |  | 9 |
| **E** |  | 6 | 1 | 9 |  |

Найдите длину кратчайшего пути из A в E, **проходящего через D**.

<details><summary>Ответ</summary>

**9**

A → D (2), затем D → C → E (6 + 1 = 7), что короче D → E (9). Итого 2 + 7 = 9.

</details>

### Задача 3

|   | A | B | C | D | E | F |
|---|---|---|---|---|---|---|
| **A** |  | 1 | 4 |  |  |  |
| **B** | 1 |  | 2 | 5 |  |  |
| **C** | 4 | 2 |  | 1 | 6 |  |
| **D** |  | 5 | 1 |  | 2 | 2 |
| **E** |  |  | 6 | 2 |  | 1 |
| **F** |  |  |  | 2 | 1 |  |

Найдите длину кратчайшего пути из A в F.

<details><summary>Ответ</summary>

**6**

A → B → C → D → F: 1 + 2 + 1 + 2 = 6.

</details>

### Задача 4

Таблица из задачи 3. Найдите длину кратчайшего пути из A в F, **не проходящего через C**.

<details><summary>Ответ</summary>

**8**

Без C: A → B → D → F = 1 + 5 + 2 = 8 (через E: A → B → D → E → F = 1 + 5 + 2 + 1 = 9).

</details>

### Задача 5

|   | A | B | C | D | E | F |
|---|---|---|---|---|---|---|
| **A** |  | 3 | 7 |  |  |  |
| **B** | 3 |  | 2 | 4 |  |  |
| **C** | 7 | 2 |  |  | 3 |  |
| **D** |  | 4 |  |  | 1 | 6 |
| **E** |  |  | 3 | 1 |  | 2 |
| **F** |  |  |  | 6 | 2 |  |

Найдите длину кратчайшего пути из A в F. Сколько существует **различных** путей такой длины?

<details><summary>Ответ</summary>

**10; 2 пути**

A → B → C → E → F = 3 + 2 + 3 + 2 = 10 и A → B → D → E → F = 3 + 4 + 1 + 2 = 10.

</details>
